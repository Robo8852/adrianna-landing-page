# primitives

> **What this covers:** The low-level visual atoms of the design system — decorative marks, rules, typographic elements, the brand sigil, and the base button — that everything else is composed from.

## What
- Primitives are the smallest reusable visual units in the app: a single rule line, a single arrow glyph, a drop cap, a heading block, the brand mark. They render one self-contained piece of UI and take a handful of presentational props.
- They differ from **composites** (which combine several primitives, e.g. `PullQuote` and `SectionHeading` themselves wrap `GoldRule`) and from **sections** (full page bands with content, layout, and copy). A primitive never owns page layout or business content — it only renders a styled atom and exposes knobs (size, color, width, variant, animate).
- All of these except `button.tsx` live under `showcase/components/primitives/` and share the brand's parchment/ink-green/gold palette and serif type stack. `button.tsx` is the shadcn/ui base button (Tailwind/CVA), conceptually a primitive but stylistically separate from the brand atoms.

## Where
- `showcase/components/primitives/ArrowGlyph.tsx` — inline SVG arrow (line + chevron) in a 16×16 viewBox. Props: `size` (12), `direction` (`"right"|"left"`, flips via `scaleX(-1)`), `color` (`currentColor`), `strokeWidth` (1.5), `className`. Server component, `aria-hidden`, `inline-block`/`vertical-align: middle`.
- `showcase/components/primitives/DropCap.tsx` — a `<p>` of body copy whose `::first-letter` is enlarged to a 5rem gold Cormorant drop cap (via `styled-jsx`). Props: `children`, `className`. Client component (`styled-jsx`). Body text in EB Garamond / parchment.
- `showcase/components/primitives/GoldRule.tsx` — a 1px gold gradient divider (transparent→gold→transparent) that scales in horizontally on scroll. Props: `width` (`"16rem"`), `opacity` (0.85), `animate` (true), `className`. Client component; uses `useReveal` (threshold 0.4) to toggle `scaleX(0)→scaleX(1)` with a 1s transition. The most widely reused primitive — embedded inside `PullQuote` and `SectionHeading`.
- `showcase/components/primitives/IlluminatedMarker.tsx` — a centered decorative marker. Props: `variant` (`"plus"|"triplet"`), `color` (`var(--gold)`), `size` (14), `className`. `"plus"` renders a centered `+` in Cormorant; `"triplet"` renders three 4px gold dots in a row. Server component, `aria-hidden`.
- `showcase/components/primitives/MicroSigil.tsx` — small line-art emblem in a 64×64 viewBox with a draw-on (stroke-dashoffset) animation. Props: `motif` (required: `"vessel"|"vesica"|"vine"|"plumb-line"|"interlocking-lobes"`), `size` (36), `gold` (`#C9A961`), `strokeWidth` (1.5), `className`, `ariaLabel`. Client component; uses `useReveal` (threshold 0.5) + local `styled-jsx` keyframes (`micro-sigil-draw`, 1.8s) gated on a `.revealed` class; honors `prefers-reduced-motion`. `role="img"` with motif-derived aria label.
- `showcase/components/primitives/MottoLine.tsx` — a centered uppercase motto line wrapped in gold em-dashes. Props: `text` (default `"LUX · VERITAS · FORMA"`), `size` (`"0.78rem"`), `className`. Server component; Cormorant, `gold-warm` text, 0.4em tracking.
- `showcase/components/primitives/PullQuote.tsx` — a `<figure>` blockquote: top `GoldRule`, italic EB Garamond quote with decorative gold curly quotes, optional small-caps `<figcaption>` attribution, bottom `GoldRule`. Props: `quote` (required), `attribution?`, `className`. Client component (wraps `GoldRule`). Composite-leaning but lives here as a typographic primitive.
- `showcase/components/primitives/SectionHeading.tsx` — a centered heading block: `GoldRule` / heading / `GoldRule`. Props: `as` (`"h2"|"h3"`), `size` (`"2.25rem"`), `tracking` (`"0.18em"`), `smallCaps` (true → uppercase), `ruleWidth` (`"6rem"`), `id`, `children`, `className`. Client component; Cormorant, parchment, weight 400.
- `showcase/components/primitives/Sigil.tsx` — **the brand logo** ("The Altar Within" — woven interlocking cross). 25 open stroked `<path>`s in a 1072×1072 viewBox that ink themselves on top-to-bottom. Props: `size` (148), `animated` (true), `gold` (`#C9A961`), `goldWarm` (unused, API-compat — `void goldWarm`), `strokeWidth` (16), `ariaLabel`, `className`. Client component; `role="img"`.
- `showcase/components/ui/button.tsx` — shadcn/ui base button. CVA `buttonVariants`: `variant` (`default|destructive|outline|secondary|ghost|link`), `size` (`default|sm|lg|icon`). Props: standard button attrs + `asChild` (Radix `Slot`). `forwardRef`, exports `Button` + `buttonVariants`. Tailwind/theme-token styled (`bg-primary`, etc.), NOT the brand gold palette.

## How
- **Styling approach is mixed.** The brand primitives style almost entirely via **inline `style` objects referencing CSS custom properties** (`var(--gold)`, `var(--gold-warm)`, `var(--parchment)`, `var(--ink-green)`) and the font-family CSS vars (`var(--font-cormorant)`, `var(--font-eb-garamond)`), not Tailwind classes. `button.tsx` is the lone exception — it uses Tailwind + CVA + the `cn` helper (`@/lib/utils`) and shadcn semantic tokens (`bg-primary`, `text-primary-foreground`, `ring-ring`). Don't expect brand-gold output from `button.tsx` as-is.
- **Design tokens (other domain):** defined in `showcase/app/globals.css` `:root` — `--ink-green: #0B3B36`, `--gold: #C9A961`, `--gold-warm: #D9BE7E`, `--parchment: #F3EEDA`, `--shadow: #061F1C`. Font CSS vars are injected by the layout/font setup. Hard-coded hex defaults in `MicroSigil`/`Sigil` (`#C9A961`, `#D9BE7E`) mirror these tokens — keep them in sync if tokens change.
- **Prop conventions:** every primitive takes an optional `className` (merged or appended, never replacing inline styles) and presentational-only props with sensible brand defaults; most use `= {}` default-param so they can be called with no args. Required content props are positional in the destructure (`quote`, `motif`, `children`). Colors default to `currentColor` (`ArrowGlyph`) or a gold token/hex.
- **Client vs server:** components are server components by default; the `"use client"` directive appears only where needed — `styled-jsx` (`DropCap`, `MicroSigil`), the `useReveal` hook (`GoldRule`, `MicroSigil`, and transitively `PullQuote`/`SectionHeading` which import `GoldRule`), or `Sigil` (animation). Pure-static atoms (`ArrowGlyph`, `IlluminatedMarker`, `MottoLine`) are server components.
- **Animation / reveal (depends on `showcase/lib/hooks/useReveal.ts`):** `useReveal` is an IntersectionObserver hook returning `{ ref, revealed }`; it returns `revealed: true` immediately under `prefers-reduced-motion`. `GoldRule.animate` (default true) drives a `scaleX` transform; set `animate={false}` for an always-extended static rule. `MicroSigil` uses `useReveal` + scoped keyframes to draw its strokes once in view.
- **Sigil specifics:** This is the freshly re-traced brand mark. The JPG (`landing-page-assets/photo_2026-05-10_18-36-19.jpg`) was isolated, skeletonized to single-pixel centerlines, and exported as **open stroked paths** (uniform strokes, not fills) so the lines stay crisp and each one can ink on. When `animated` (default), each `<path>` gets `className="altar-sigil-trace"` plus **inline** `strokeDasharray`/`strokeDashoffset` (= that path's length) and a staggered `animationDelay`/`animationDuration` — the shared `@keyframes altar-sigil-draw` (animating `stroke-dashoffset → 0`) lives in `showcase/app/globals.css` along with the `.altar-sigil-trace` rule and a `prefers-reduced-motion` override that snaps `stroke-dashoffset: 0`. `goldWarm` is accepted but unused (`void goldWarm`) — kept for API stability. Backups exist as `Sigil.filled.bak.tsx` (filled-outline) and `Sigil.handcoded.bak.tsx` (original hand-authored); to swap in a higher-res source, regenerate only the path `d`/lengths and keep the props/API identical.
- **When to reuse vs build new:** need a divider → `GoldRule`. Need a section title → `SectionHeading`. Need a quote → `PullQuote`. Need a small decorative emblem → `MicroSigil` (pick a `motif`) or `IlluminatedMarker` (plus/triplet). Need the logo → `Sigil`. Build a new primitive only for a genuinely new atom; compose existing primitives for anything larger (that's a composite/section, not a primitive).
- **Gotchas:** (1) `MicroSigil.motif` and `PullQuote.quote` are required — no default. (2) `GoldRule`/`MicroSigil` need to scroll into view to render their animated state; in tests/SSR snapshots they start collapsed/undrawn until `revealed`. (3) `Sigil` per-path `strokeDasharray` numbers are precomputed path lengths — if you edit a path's `d`, recompute its length or the draw-on will under/overshoot. (4) `button.tsx` lives under `components/ui/` (shadcn), not `components/primitives/`, and uses Tailwind tokens rather than the brand CSS vars.
